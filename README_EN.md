# shingja's Engineering Student Handbook

**Competitions, projects, tools, and lessons learned the hard way.**

A continuously updated handbook for engineering undergraduates at the University of Science and Technology Beijing (USTB). It covers information literacy, document production, code and data workflows, project execution, and risk/compliance.

The software chapters are written as step-by-step operational guides. The project chapters deliberately provide frameworks and checklists rather than specific competition topics, because the right direction changes every year.

The experience section may mention competition names, but never specific project content, teammate identities, or award lists.
