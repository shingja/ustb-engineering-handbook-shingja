# 提交包检查

提交前 24 小时逐条打勾。

- [ ] 提交物清单与竞赛通知逐项对应，没有漏项。
- [ ] 文件命名符合要求（项目名/赛道/版本/日期）。
- [ ] 所有文档能正常打开，没有损坏、乱码、缺字体。
- [ ] PDF 已检查分页、目录、图表编号、公式编号。
- [ ] 图片分辨率足够，放大不模糊。
- [ ] 视频/演示文件能在目标设备播放。
- [ ] 压缩包解压后目录结构正确，没有多余文件。
- [ ] 压缩包内没有 `.git`、`node_modules`、缓存、临时文件。
- [ ] 文档属性已清理（作者、单位、私人邮箱）。
- [ ] 代码/数据中的密钥、内网地址、测试账号已删除。
- [ ] 队友信息、未公开项目内容已脱敏。
- [ ] 提交账号、密码、验证码可用，网络环境正常。
- [ ] 已提前提交一次测试，确认系统接收。
- [ ] 保留一份最终版备份，记录提交时间与回执。
