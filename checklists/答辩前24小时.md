# 答辩前 24 小时

- [ ] PPT 能在答辩电脑上打开，字体没有缺失。
- [ ] PPT 没有自动播放、外链视频、需要联网的素材。
- [ ] 演示视频已导出为本地文件，并备份。
- [ ] 翻页器/遥控器已测试，电池可用。
- [ ] 讲稿控制在规定时间内，至少完整试讲两遍。
- [ ] 每页只讲一个结论，图表有标题和单位。
- [ ] 预设 5 个可能被问的问题，写出回答要点。
- [ ] 关键数据、公式、对比结果能脱稿说清。
- [ ] 团队成员分工：谁主讲、谁补充、谁记录问题。
- [ ] 提交版 PPT/论文/代码已备份到 U 盘和云端。
- [ ] 提前确认场地、时间、签到方式、着装要求。
- [ ] 睡够。答辩当天状态比多改一页 PPT 更重要。
