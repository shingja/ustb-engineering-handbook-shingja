# 卷三 · 代码与数据力

不是只有计算机专业才需要代码。机械、自动化、材料、能源，只要涉及数据、仿真、控制、图像，就绕不开：

- 环境能不能重装。
- 结果能不能复现。
- 代码能不能被别人接手。
- 版本能不能回退。

- [可视化与出图](可视化与出图.md)：图表选择、配色、坐标轴、图注、导出。
- [VS Code 配置](VSCode配置.md)：工作区、解释器、插件最小集、远程开发。
- [代码质量与测试](代码质量与测试.md)：结构、命名、注释、日志、单元测试。
