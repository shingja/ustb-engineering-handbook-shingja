# 可视化与出图

## 适用场景

你要把实验结果放进论文/答辩/报告；图被说“看不清”“配色太花”“没有误差棒”；导出后字体模糊。

## 最小做法

### 先定结论，再选图

- 比较类别：柱状图。
- 趋势：折线图。
- 分布：直方图/箱线图。
- 两个变量关系：散点图。
- 占比：饼图（类别少）。
- 多指标对比：雷达图慎用，容易误导。

一张图只表达一个结论。标题写结论，不写“结果图”。

### 坐标轴与图注

- 横纵轴都有标题和单位。
- 刻度从 0 开始（除非有充分理由截断）。
- 图例不遮挡数据。
- 图注写清：样本量、条件、误差棒含义、显著性标记。
- 颜色盲友好：避免红绿对比，用蓝/橙、紫/黄。

### Matplotlib 最小模板

```python
import matplotlib.pyplot as plt
import numpy as np

x = np.array([1, 2, 3, 4])
y = np.array([2.1, 3.9, 6.2, 8.1])
err = np.array([0.2, 0.3, 0.2, 0.4])

fig, ax = plt.subplots(figsize=(6, 4), dpi=300)
ax.errorbar(x, y, yerr=err, fmt="o-", capsize=4, color="#2563eb")
ax.set_xlabel("时间 / s")
ax.set_ylabel("位移 / mm")
ax.set_title("位移随时间线性增加")
ax.grid(alpha=0.3)
fig.tight_layout()
fig.savefig("figure.png", dpi=300, bbox_inches="tight")
```

### 导出

- 论文/报告优先矢量图：PDF/SVG。
- 位图至少 300 DPI，宽度按版面定。
- 导出前检查：字体嵌入、中文不乱码、线宽、图例。
- 不要用截图；截图无法放大。

## 进阶做法

- 用统一色板和字号，保证多张图风格一致。
- 用 `seaborn` 快速画统计图，但不要默认主题直接用。
- 用 `SciencePlots` 或期刊模板调整样式。
- 多面板图用 `subplots`，标 `(a)(b)(c)`。
- 误差棒写清是标准差、标准误还是置信区间。
- 颜色之外再加线型/标记，黑白打印也能区分。

## 常见坑

- 3D 柱状图、渐变、阴影，读者看不清数值。
- 饼图类别太多，角度无法比较。
- 坐标轴截断，夸大差异。
- 没有误差棒/样本量，结论不可信。
- 图注只写“结果如图”，没有条件说明。
- 中文乱码：没设置中文字体。
- 导出 PNG 72 DPI，打印模糊。
- 颜色红绿搭配，色盲读者无法区分。

## 版本与时效

本文基于 Matplotlib 3.10、Python 3.11。绘图库版本会变，但“先结论后图 + 坐标轴/图注完整 + 矢量导出”的原则不变。
