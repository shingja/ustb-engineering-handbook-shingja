# 排版、打印与 PDF

## 适用场景

文档在电脑上好看，打印/导出后分页乱、字体变、图表被截断；提交系统只收 PDF；论文格式审查总被打回。

## 最小做法

### 先看要求

- 学校/竞赛/期刊有没有模板？有就先用模板，不要自创。
- 页边距、字体、字号、行距、页码位置，逐项对照。
- 摘要/正文/参考文献的格式可能不同。
- 文件名、文件大小、页数限制。

### 页面设置

- A4，页边距按模板：常见上下 2.54 cm、左右 3.17 cm，或学校指定值。
- 正文宋体/仿宋，标题黑体，英文 Times New Roman；以模板为准。
- 行距 1.5 倍或固定值 20-22 pt。
- 页码从正文开始，封面/目录不编号。
- 页眉写论文/项目名，页脚写页码。

### 分页与分节

- 封面、目录、正文、附录之间用“分节符（下一页）”，不要连按回车。
- 不同节可以设不同页眉/页码。
- 图表不要跨页；表格跨页时重复表头。
- 标题不要单独留在页底（与下段同页）。

### 导出 PDF

1. 更新目录、交叉引用、图表编号。
2. 接受所有修订，删除批注。
3. 文件 → 导出 → PDF，勾选“创建书签时使用标题”。
4. 检查：字体嵌入、分页、图表、公式、页码、超链接。
5. 用另一台设备/阅读器打开一次。

### 打印检查

- 先打一份黑白草稿，检查灰度对比。
- 彩色图打印后是否还能区分。
- 装订线是否留够。
- 双面打印时奇偶页页边距是否对称。

## 进阶做法

- 用样式统一全文，不要手动调。
- 用“域”做页码、目录、交叉引用，改内容自动更新。
- 长文档拆成多个子文档，最后合并。
- 用 PDF 工具压缩图片，控制文件大小。
- 提交前用 `pdfinfo`/阅读器检查页数、字体、元数据。

## 常见坑

- 用回车/空格排版，改一个字全乱。
- 目录没更新，页码对不上。
- 字体没嵌入，别人打开变宋体/乱码。
- 图表跨页，读者要翻页对照。
- 修订/批注没删，直接交稿。
- 文件名含空格/中文，系统上传失败。
- PDF 是扫描件，文字不可检索。

## 自检清单

- [ ] 对照了学校/竞赛/期刊模板。
- [ ] 页边距、字体、行距、页码符合要求。
- [ ] 封面/目录/正文分节，页码正确。
- [ ] 图表不跨页，表头可重复。
- [ ] 目录、交叉引用已更新。
- [ ] 修订已接受，批注已删除。
- [ ] PDF 字体嵌入、分页、书签正常。
- [ ] 换设备打开检查过。

## 版本与时效

本文基于 Word 2024 与常见 PDF 阅读器。模板要求每年可能变，以当年官方文件为准。
