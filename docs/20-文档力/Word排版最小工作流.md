# Word 排版最小工作流

## 适用场景

你要写课程报告、竞赛申报书、论文或项目结题材料。文档会反复修改，图、表、章节会增删，最后还要导出 PDF。

## 最小做法

<img src="/diagrams/word.svg" alt="图：Word 排版最小流程" width="680" style="max-width:100%">

### 第一步：先定样式，不先写正文

打开 Word，先把这几类样式定好：

| 样式 | 用途 | 关键设置 |
|---|---|---|
| 标题 1 | 一级标题 | 黑体/加粗，段前段后，与下段同页 |
| 标题 2 | 二级标题 | 字号递减，编号跟随 |
| 标题 3 | 三级标题 | 尽量少用 |
| 正文 | 主体文字 | 首行缩进 2 字符，1.5 倍行距 |
| 图注 | 图下方说明 | 小一号字，居中 |
| 表注 | 表上方说明 | 小一号字，居中 |
| 公式 | 独立公式 | 居中，编号右对齐 |

样式定好后，写作时只点样式，不用手动调字号、加粗、空格。

### 第二步：用多级列表管章节编号

1. 在“开始”里点“多级列表” → “定义新的多级列表”。
2. 把级别 1 链接到“标题 1”，级别 2 链接到“标题 2”。
3. 编号格式设为 `1`、`1.1`、`1.1.1`。
4. 正文里的“第一章”“1.1”不要手打，交给列表。

这样插入或删除章节时，编号会自动更新。

### 第三步：图、表、公式用题注

- 选中图 → 引用 → 插入题注 → 新建标签“图”。
- 表：题注放在表上方；图：题注放在图下方。
- 公式：用“插入 → 公式”，编号可以用表格或制表位实现。

题注的作用不是好看，是让交叉引用能自动更新。

### 第四步：正文引用用交叉引用

在正文里写“如图 3 所示”时：

1. 引用 → 交叉引用 → 引用类型选“图”。
2. 选择对应题注，插入。
3. 图号变化后，全选 → F9 更新域。

不要手打“图 3”。手打的编号，插入一张图就会全乱。

### 第五步：三线表

学术文档常用三线表：

1. 插入表格，填内容。
2. 选中表格 → 边框 → 无框线。
3. 只保留顶线、表头下线、底线。
4. 表注放在表格上方，写清单位、样本量、显著性标记。

如果学校/期刊有模板，优先用模板，不要自创格式。

### 第六步：目录与 PDF

1. 正文标题必须用“标题 1/2/3”样式。
2. 引用 → 目录 → 自动目录。
3. 导出前：Ctrl+A → F9 → 更新整个目录。
4. 文件 → 导出 → PDF，勾选“创建书签时使用标题”。
5. 打开 PDF 检查：目录页码、图表编号、公式编号、分页、字体是否嵌入。

## 进阶做法

- 用“样式集”统一全文档，不要逐个改。
- 给长文档加“分节符”，不同章节用不同页眉页脚。
- 用“修订”模式改稿，接受后再导出。
- 图片统一 300 DPI，宽度不超过版心。
- 公式用 Word 自带公式编辑器，方便后期修改。

## 常见坑

- 用空格/回车对齐，改字号就全乱。
- 手动打章节号、图号、表号，插入内容后编号错位。
- 从网页复制内容，带入一堆隐藏格式。
- 目录不更新就导出，页码对不上。
- 修订没接受、批注没删除，直接交稿。
- 图片是截图，放大后模糊。
- 字体未嵌入，别人打开 PDF 变宋体/乱码。

## 自检清单

- [ ] 全文只用样式控制标题和正文。
- [ ] 章节编号由多级列表生成。
- [ ] 图、表、公式都有题注。
- [ ] 正文引用使用交叉引用，没有手打编号。
- [ ] 目录已更新，页码正确。
- [ ] 修订已接受，批注已删除。
- [ ] PDF 已检查分页、图表、字体。
- [ ] 文件属性里没有不该出现的作者/单位信息（公开前必查）。

## 版本与时效

本文基于 Microsoft Word 2024（16.0）界面。Word 2016/2019/365 的菜单名称基本一致，位置可能略有差异。WPS 的操作路径不同，但“样式—题注—交叉引用—目录”的逻辑相同。
