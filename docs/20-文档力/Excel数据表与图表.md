# Excel 数据表与图表

## 适用场景

你要整理实验数据、做分工表、统计报名信息、画对比图，或者把一堆 CSV 合并成一张表。

## 最小做法

### 数据表先定结构

一张表只做一件事，第一行是表头，每列一个字段：

| 日期 | 项目 | 负责人 | 数值 | 单位 | 备注 |
|---|---|---|---|---|---|
| 2026-10-01 | A | 张三 | 12.3 | mm |  |
| 2026-10-02 | A | 李四 | 12.5 | mm |  |

规则：

- 不合并单元格。
- 不在表头上面加标题行。
- 一列只放一种数据类型。
- 空值留空，不要写 `无`、`N/A`、`-` 混用。
- 原始数据单独一个 sheet，处理过程另开 sheet。

### 常用函数

```excel
=SUM(B2:B100)
=AVERAGE(B2:B100)
=MAX(B2:B100)
=COUNTIF(C2:C100,"张三")
=SUMIF(C2:C100,"张三",D2:D100)
=IFERROR(VLOOKUP(A2,Sheet2!A:B,2,FALSE),"未找到")
=TEXT(A2,"yyyy-mm-dd")
=ROUND(D2,2)
```

- `VLOOKUP` 只适合从左往右查；复杂查询用 `XLOOKUP`（新版 Excel）。
- 查找值两边格式要一致：文本 vs 数字、前后空格都会导致 `#N/A`。
- 用 `TRIM` 去空格，用 `VALUE` 转数字。

### 透视表

1. 选中数据区域 → 插入 → 数据透视表。
2. 行：分类字段；列：对比字段；值：求和/计数/平均。
3. 原始数据更新后，右键透视表 → 刷新。

透视表适合“按类别汇总”，不适合直接当最终排版表。

### 图表选择

| 目的 | 图表 |
|---|---|
| 比较类别 | 柱状图 |
| 看趋势 | 折线图 |
| 看分布 | 直方图/箱线图 |
| 看占比 | 饼图（类别少时） |
| 看两个变量关系 | 散点图 |

规则：

- 一张图只表达一个结论。
- 坐标轴有标题和单位。
- 图例、数据标签不要遮挡。
- 颜色不超过 5 种，重点用对比色。
- 导出前把图表区域调成合适大小，不要直接截图。

## 进阶做法

- 用“表格”功能（Ctrl+T）让公式自动扩展。
- 用“数据验证”限制输入，减少脏数据。
- 用“条件格式”标出异常值。
- 用 Power Query 合并多个 CSV/Excel，步骤可复用。
- 用 `pandas` 处理超过几万行的数据，Excel 只做展示。

## 常见坑

- 合并单元格导致排序、筛选、透视表全乱。
- 数字被存成文本，求和为 0。
- 日期格式不统一，按时间排序失效。
- 图表用 3D、渐变、阴影，读者看不清数据。
- 直接改原始数据，出错无法回溯。
- 文件里藏着批注、修订、个人信息，公开前没清理。

## 自检清单

- [ ] 一张表只做一件事，第一行是表头。
- [ ] 没有合并单元格。
- [ ] 一列只有一种数据类型。
- [ ] 原始数据和处理结果分开 sheet。
- [ ] 图表有标题、坐标轴、单位。
- [ ] 图表颜色不超过 5 种，重点突出。
- [ ] 公开前清理批注、修订、个人信息。

## 版本与时效

本文基于 Microsoft Excel 2024。`XLOOKUP`、Power Query 在旧版可能不可用；WPS 的函数名称基本兼容，但菜单位置不同。
