# 卷二 · 文档力

竞赛、课程、科研，最后都要落到一份可交付的文件上。文档力不是“会用 Word”，而是：

- 知道一份文档应该有哪些结构。
- 知道样式、编号、题注、交叉引用怎么设，改内容不用手工重排。
- 知道什么内容该放正文，什么该放附录。
- 知道导出 PDF 前要检查什么。
