# 时间管理与学业平衡

## 适用场景

你在竞赛/项目/课程/英语之间来回切换；总觉得时间不够；期末和比赛撞车；不知道要不要退出某个项目。

## 我试过有效的做法

### 1. 先算“可支配时间”

一周 168 小时，扣掉睡眠、上课、吃饭、通勤，剩下才是可支配的。算完就知道“再报一个比赛”是否现实。

### 2. 按“不可逆性”排优先级

- 考试/绩点：影响保研/毕业，优先。
- 关键竞赛节点：错过等一年。
- 科研/论文：长周期，持续投入。
- 一般活动：可替代，做减法。

不是所有比赛都值得牺牲绩点。

### 3. 每学期只留 1-2 个主线项目

同时推进 3 个以上项目，通常每个都只做一半。主线之外的项目，要么不做，要么只做明确的小模块。

### 4. 给截止时间留缓冲

官方截止前 3 天作为内部截止。打印、上传、系统崩溃、队友迟到，都需要缓冲。

### 5. 设止损线

- 连续两周无实质进展 → 检查方向/分工。
- 关键模块到某日期仍未跑通 → 启用保底方案。
- 时间超预算 30% → 重新评估是否退出。
- 课程出现挂科风险 → 优先保课程。

## 我踩过的坑

### 1. 什么都想抓

报了很多比赛，每个都只做了一点。最后没有一个是完整交付的。

### 2. 用熬夜补时间

短期能顶，第二天效率更低，错误更多。长期看，熬夜是最贵的“省时间”。

### 3. 不拒绝

队友/老师加任务就接，最后自己的主线被挤掉。学会说“我这周排满了，下周三可以”。

### 4. 期末前还在改原型

没有提前看考试时间，赛前和期末撞车，两边都做不好。

### 5. 没有缓冲

把所有时间排满，任何一个意外都会连锁反应。

## 如果重来一次

1. 每学期初算时间预算，只留 1-2 个主线。
2. 所有截止时间放进一个日历，按周看。
3. 每周留半天缓冲。
4. 给每个项目设止损线。
5. 课程风险出现时，优先保课程。
