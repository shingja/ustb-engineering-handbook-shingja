# 卷六 · 经验卷

这一卷写作者自己的经历，但有明确边界：

- 只讲决策、踩坑、取舍和团队协作。
- 不写具体竞赛、项目、奖项、名次。
- 不出现队友姓名、老师姓名、学院内部信息。
- 不把经历写成简历。

## 为什么这样写

项目内容每年都变，直接照搬别人的方案，既容易过时，也可能涉及未公开信息。真正能复用的是判断方式：

- 当时为什么选这个方向，后来发现哪里判断错了。
- 时间是怎么被消耗掉的，哪一步最容易拖。
- 队友之间怎么分工，冲突怎么处理。
- 失败之后怎么复盘，下一次提前做什么。

## 本卷篇目

- [做对了什么，做错了什么](做对了什么做错了什么.md)：反复验证有效的做法和踩过的坑。
- [团队协作与冲突](团队协作与冲突.md)：分工、沟通、冲突、退出与署名。
- [时间管理与学业平衡](时间管理与学业平衡.md)：时间预算、优先级、止损。
- [失败复盘](失败复盘.md)：没获奖、没做完、现场翻车之后怎么看。
- [给不同年级的建议](给不同年级的建议.md)：大一、大二、大三分别抓什么。

经验卷只保留可迁移的判断方式，不提供可直接照搬的项目方案。
