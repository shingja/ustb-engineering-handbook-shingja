# 终端与批量操作

## 适用场景

你要给 200 个文件改名、批量转图片格式、统计目录大小、查找重复文件，或者把手动点十遍的操作写成一条命令。

## 最小做法

### 先认识三个概念

- **当前目录**：命令默认在这里执行。`pwd` 查看，`cd` 切换。
- **管道**：把上一个命令的输出交给下一个命令。`|` 是管道符。
- **对象**：PowerShell 输出的是对象，不只是文本；可以用 `Select-Object`、`Where-Object`、`ForEach-Object` 处理。

### 常用命令

```powershell
Get-Location                 # 当前目录
Get-ChildItem                # 列出文件
Get-ChildItem -Recurse       # 递归列出
Set-Location D:\work         # 切换目录
New-Item -ItemType Directory -Name demo   # 新建目录
Copy-Item a.txt b.txt        # 复制
Move-Item a.txt archive\     # 移动
Remove-Item a.txt            # 删除（不进回收站，慎用）
Get-Content a.txt            # 读文本
Select-String "关键词" *.md  # 搜内容
```

### 批量重命名

先预览，再执行：

```powershell
Get-ChildItem *.jpg | ForEach-Object {
    $new = "2026_" + $_.Name
    Write-Host "$($_.Name) -> $new"
}
```

确认无误后加 `Rename-Item`：

```powershell
Get-ChildItem *.jpg | ForEach-Object {
    Rename-Item $_.FullName ("2026_" + $_.Name)
}
```

### 批量统计

```powershell
Get-ChildItem -Recurse -File |
  Measure-Object -Property Length -Sum |
  Select-Object Count, @{n='GB';e={[math]::Round($_.Sum/1GB,2)}}
```

### 查找大文件

```powershell
Get-ChildItem -Recurse -File |
  Sort-Object Length -Descending |
  Select-Object -First 20 FullName, @{n='MB';e={[math]::Round($_.Length/1MB,1)}}
```

## 进阶做法

- 把常用命令写成 `.ps1` 脚本，放 `tools\`，加注释和参数。
- 用 `-WhatIf` 预览危险操作（支持的命令）：

```powershell
Remove-Item *.tmp -WhatIf
```

- 用 `Tee-Object` 同时输出到屏幕和日志。
- 用 `Start-Transcript` 记录整个终端会话。
- 用 `robocopy` 做批量复制/镜像，比 `Copy-Item` 更适合大目录。

## 常见坑

- `Remove-Item` 默认不进回收站，删错很难恢复。先 `-WhatIf`，再执行。
- 路径含空格不加引号，命令被拆成两段。
- 在 `C:\Windows\System32` 下执行脚本，权限不足或改错系统文件。
- 用 `*` 通配符前不预览，批量改错全部文件。
- 直接运行来路不明的 `.ps1`，可能被执行策略或恶意脚本拦住/利用。
- 在 OneDrive 同步目录里批量改名，同步冲突翻倍。

## 自检清单

- [ ] 我知道当前目录是什么。
- [ ] 批量操作前先用 `Write-Host` 或 `-WhatIf` 预览。
- [ ] 删除操作前确认有备份。
- [ ] 脚本放在项目 `tools\` 下，不进系统目录。
- [ ] 路径含空格时加了引号。
- [ ] 重要操作有日志。
- [ ] 陌生脚本先读内容，再决定是否执行。

## 版本与时效

本文基于 PowerShell 7 与 Windows 11。PowerShell 5.1 的语法基本兼容，但部分参数不同；`robocopy` 行为长期稳定。
