# 浏览器插件与脚本风险

## 适用场景

你装了很多浏览器插件，网页变慢、弹广告；有人发来“油猴脚本”说能自动刷课/解锁功能；登录学校系统时担心插件读取密码。

## 最小做法

### 插件最小化

只保留三类：

1. 必需：密码管理器、翻译、文献抓取。
2. 高频：广告拦截、阅读模式。
3. 开发：调试工具，用完关掉。

其余插件停用或卸载。插件不是越多越好，每个插件都能读你打开的网页。

### 看权限

安装前看它要求什么权限：

- “读取和更改所有网站上的数据”：权限很大，谨慎。
- “读取浏览历史”：不需要就别给。
- “管理下载”：下载类插件才需要。
- “读取剪贴板”：很少有必要。

权限和功能不匹配的插件，不装。

### 油猴脚本的风险

油猴（Tampermonkey）本身是脚本管理器，风险来自脚本：

- 脚本可以读页面内容、发请求、改按钮。
- 来路不明的脚本可能偷 cookie、token、表单内容。
- “自动刷课/自动答题/解锁会员”类脚本，除了安全风险，还有学术诚信和封号风险。

原则：只装能看懂、来源可查、更新活跃的脚本；涉及账号、支付、学校系统的页面，关掉脚本再操作。

### 账号隔离

- 学校/银行/邮箱等重要账号，用一个干净的浏览器配置文件，不装杂七杂八插件。
- 日常浏览用另一个配置文件。
- 密码管理器开自动填充，但重要操作手动确认域名。

## 进阶做法

- Chrome/Edge 建多个配置文件：`School`、`Daily`、`Dev`。
- 用 `chrome://extensions` 查看每个插件的“详细信息 → 网站访问权限”，改成“点击时”。
- 定期导出插件清单，重装系统后按需恢复。
- 用浏览器自带的增强保护/安全浏览，但不要替代密码管理器。
- 涉及登录的脚本，先在无痕窗口测试，确认不会自动提交表单。

## 常见坑

- 装“免费 VPN/加速器”插件，实际在卖流量或注入广告。
- 给插件“所有网站”权限，登录页也被读取。
- 用来路不明的油猴脚本刷课，账号被封或密码泄露。
- 插件长期不更新，漏洞没人修。
- 在装了十几个插件的浏览器里登录学校系统，出问题难排查。
- 把密码保存在浏览器明文/弱同步里，不开主密码。

## 自检清单

- [ ] 我只保留必需、高频、开发三类插件。
- [ ] 每个插件的权限和功能匹配。
- [ ] 重要账号用独立浏览器配置文件。
- [ ] 油猴脚本来源可查，能看懂关键逻辑。
- [ ] 登录/支付页面关闭脚本和可疑插件。
- [ ] 密码管理器开启，重要操作手动确认域名。
- [ ] 定期清理不用的插件。

## 版本与时效

本文基于 Chrome/Edge 2026 版。插件名称和菜单会变，但“权限最小化 + 账号隔离 + 脚本审慎”的原则不变。
