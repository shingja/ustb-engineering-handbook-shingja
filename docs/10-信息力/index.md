# 卷一 · 信息力

工科学习里，很多时间不是花在“做”，而是花在“找”和“理”。这一卷解决四个问题：

1. 去哪里找，找到的东西可不可信。
2. 文件怎么命名、怎么放、怎么备份，才不至于三天后找不到。
3. 终端和系统工具怎么用，才能批量处理而不是手工重复。
4. 磁盘、编码、压缩包这些底层小事，怎么不踩坑。

## 本卷章节

- [检索与来源验证](检索与来源验证.md)：从关键词到可验证来源。
- [文件系统与命名](文件系统与命名.md)：目录、命名、路径、快捷方式。
- [备份与同步](备份与同步.md)：3-2-1 原则、OneDrive 冲突、恢复演练。
- [编码、后缀与压缩包](编码后缀与压缩包.md)：UTF-8/GBK、BOM、换行、压缩格式。
- [终端与批量操作](终端与批量操作.md)：PowerShell、路径、管道、批量重命名。
- [浏览器插件与脚本风险](浏览器插件与脚本风险.md)：权限、油猴脚本、账号隔离。
- [磁盘空间与软件清理](磁盘空间与软件清理.md)：空间排查、卸载、分区扩容。
- [信息甄别](信息甄别.md)：AI 生成内容、营销号、过期政策。
