# 磁盘空间与软件清理

## 适用场景

C 盘爆红；软件装完找不到卸载入口；想扩容分区但怕丢数据；清理完发现误删了项目文件。

## 最小做法

### 先看空间去哪了

```powershell
Get-PSDrive -PSProvider FileSystem | Select-Object Name, Used, Free
```

找大目录：

```powershell
Get-ChildItem C:\ -Directory -Force -ErrorAction SilentlyContinue |
  ForEach-Object {
    $size = (Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue |
             Measure-Object Length -Sum).Sum
    [PSCustomObject]@{ Path=$_.FullName; GB=[math]::Round($size/1GB,2) }
  } | Sort-Object GB -Descending | Select-Object -First 15
```

### 安全清理顺序

1. 回收站。
2. 浏览器缓存、下载目录。
3. 软件缓存（微信/QQ/网盘/IDE）。
4. Windows 更新缓存（用系统“磁盘清理”）。
5. 不用的软件。
6. 最后才考虑分区调整。

不要直接删 `C:\Windows`、`Program Files`、`Users\<user>\AppData` 里不认识的目录。

### 卸载软件

- 优先用软件自带卸载器。
- 卸载后用 Revo Uninstaller 等工具扫残留（可选）。
- 卸载前确认没有项目依赖它；比如 Python 环境、CUDA、驱动。
- 破解软件、来路不明的“绿色版”不要装，卸载也可能卸不干净。

### 分区与扩容

- 分区调整前必须备份。
- Windows 磁盘管理只能把相邻的未分配空间合并到分区。
- 跨分区调整用 DiskGenius/分区助手，操作前断电风险要考虑。
- C 盘扩容优先“压缩相邻 D 盘 → 扩展 C 盘”，不要跨物理磁盘。
- BitLocker/设备加密开启时，先暂停保护再操作。

## 进阶做法

- 用 `WizTree`/`TreeSize` 可视化空间占用，比递归命令快。
- 把大文件（数据集、视频、模型权重）移到数据盘，用符号链接接回：

```powershell
New-Item -ItemType SymbolicLink -Path "D:\work\data" -Target "E:\datasets\project"
```

- 给软件安装目录统一到 `D:\apps`，避免 C 盘越来越满。
- 用 `winget` 管理软件安装/升级：

```powershell
winget list
winget upgrade --all
```

- 定期导出已安装软件清单，重装系统后按需恢复。

## 常见坑

- 直接删 `AppData`，软件配置全丢。
- 用“一键清理”工具删注册表/系统文件，系统不稳定。
- 分区调整中途断电，分区表损坏。
- 把项目放在 C 盘桌面，重装系统一起没。
- 卸载 Python/驱动后，依赖它的项目全部跑不起来。
- 只看“可用空间”，不看“临时文件/休眠文件/虚拟内存”。

## 自检清单

- [ ] 我知道空间被哪些目录占用。
- [ ] 清理前有备份，重要文件不在 C 盘桌面。
- [ ] 卸载软件前确认没有项目依赖。
- [ ] 分区操作前备份并接通电源。
- [ ] 不使用来路不明的“一键清理/破解”工具。
- [ ] 大文件放数据盘，用符号链接接回。
- [ ] 定期更新软件，保留安装清单。

## 版本与时效

本文基于 Windows 11、PowerShell 7、winget。分区工具和系统菜单会变，但“先备份、再动分区”的顺序不变。
