# 竞赛值不值得参加

## 适用场景

新学期开始，群里转发了一堆竞赛通知；或者你已经报了一个比赛，但不确定要不要继续投入。你需要一个判断框架，而不是一句“多参加总没坏处”。

## 最小做法

用四个维度打分，每个维度 1-5 分，总分不作为绝对标准，但能逼你把问题想清楚。

### 维度一：认可度

- 学校/学院的竞赛名录里有没有它？
- 保研、评奖、学分认定是否认可？以当年文件为准。
- 赛事本身是否有稳定的评审机制和公开规则？

查证方法：学校教务处/学院官网 → 当年的竞赛认定文件；竞赛官网 → 主办方、章程、往届评审。不要只看培训机构的宣传。

### 维度二：能力匹配

- 你需要补多少新技能？两周能补完，还是两个月？
- 队伍里有没有人能覆盖关键环节（机械、电控、算法、写作、答辩）？
- 你在这个项目里具体负责什么？如果说不清，大概率会变成“打杂”。

### 维度三：时间成本

粗算一下：

```text
总投入 ≈ 备赛周数 × 每周小时数 + 冲刺期额外小时
```

再对照你的课程、考试、科研、其他竞赛。如果总投入超过你能稳定拿出的时间，结果通常是“报名了，但没做完”。

### 维度四：复用性

一次投入能不能沉淀成至少两样东西：

- 一篇论文/专利/软著；
- 毕业设计的一部分；
- 下一场比赛的原型；
- 一项能写进简历的硬技能；
- 一套可复用的代码/文档/流程。

只能拿一个名次、不能沉淀的竞赛，性价比通常不高。

## 进阶做法

### 组队前问三个问题

1. **谁负责什么？** 具体到模块和交付物，不写“大家一起做”。
2. **失败了怎么办？** 是继续迭代、转投其他比赛，还是及时止损？
3. **退出机制是什么？** 有人中途退出，工作怎么交接，署名怎么处理？

这三个问题不问清楚，后期大概率会出矛盾。

### 把“不参加”当成一个正式决策

不参加不是懒。把时间留给绩点、科研、英语、实习，可能回报更高。关键是想清楚：

- 你放弃的是什么？
- 你换来了什么？
- 这个交换在一年后还成立吗？

### 用“最小可交付”反推

先问：这个比赛最少要交什么？然后倒推：

- 报名截止：
- 初稿截止：
- 原型完成：
- 测试完成：
- 答辩准备：

每个节点写一个负责人和一个可验收的产物。

## 常见坑

- 看别人报就报，最后队伍里没人真正负责。
- 只算比赛那几天，不算前期准备和后期返工。
- 选了一个和自身能力完全不匹配的赛道，靠熬夜硬撑。
- 为了“加分”参加多个比赛，每个都只做了一半。
- 不查当年政策，拿去年的认定文件做决定。
- 组队靠关系，不分工，最后一个人扛全部。

## 自检清单

- [ ] 我查过学校/学院当年的竞赛认定文件。
- [ ] 我能说清这个比赛要交什么、什么时候交。
- [ ] 我算过总时间投入，并和课程/考试对照过。
- [ ] 我知道自己具体负责哪个模块。
- [ ] 队伍里关键环节都有人覆盖。
- [ ] 我们讨论过失败和退出机制。
- [ ] 这个项目至少能沉淀出两样可复用的东西。

## 版本与时效

本文只给判断框架，不评价任何具体赛事的含金量。学校认定政策、赛事规则每年都可能变化，务必以当年官方文件为准。
