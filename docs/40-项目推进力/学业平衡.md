# 学业平衡

## 适用场景

竞赛/项目挤占课程时间；期末和比赛撞车；什么都想抓，结果每样都差一点；不知道该不该退出某个项目。

## 最小做法

### 先算时间预算

一周 168 小时，先扣掉：

- 睡眠 49 小时（7 小时/天）。
- 上课/实验 30-40 小时。
- 吃饭/通勤/杂事 20 小时。
- 剩余 60-70 小时。

再分配给：

- 作业/复习：20-25 小时。
- 竞赛/项目：15-20 小时。
- 英语/科研/其他：5-10 小时。
- 休息/社交：10 小时。

算完就知道“再加一个比赛”是否现实。

### 定优先级

按“不可逆性”排序：

1. 考试/绩点（影响保研/毕业）。
2. 关键竞赛节点（错过等一年）。
3. 科研/论文（长周期）。
4. 一般竞赛/活动（可替代）。

不是所有比赛都值得牺牲绩点。

### 设止损线

- 连续两周项目没有实质进展 → 检查方向/分工。
- 关键模块到某日期仍未跑通 → 启用保底方案。
- 时间投入超过预算 30% → 重新评估是否退出。
- 课程出现挂科风险 → 优先保课程。

止损不是失败，是把资源挪到更重要的地方。

### 期末/赛前撞车

- 提前 4 周看考试/截止时间，做冲突表。
- 能提前交的作业提前做。
- 能拆的模块提前冻结。
- 和队友/老师沟通，调整分工。

## 进阶做法

- 用日历把所有截止时间放一起，按周看。
- 每周留半天“缓冲”，处理突发。
- 用番茄钟/时间块，避免“看起来很忙”。
- 竞赛项目按“可交付”拆，不按“工时”堆。
- 每学期只保留 1-2 个主线项目，其他做减法。

## 常见坑

- 报了一堆比赛，每个都只做一半。
- 期末前还在改原型，考试裸考。
- 不会拒绝，队友/老师加任务就接。
- 用熬夜补时间，第二天效率更低。
- 没有止损线，沉没成本越陷越深。
- 只看竞赛，忽略英语/科研的长期价值。
- 把所有时间排满，没有缓冲。

## 自检清单

- [ ] 我算过每周可支配时间。
- [ ] 我知道当前项目的优先级。
- [ ] 我给每个项目设了止损线。
- [ ] 期末/赛前冲突有提前安排。
- [ ] 每周留了缓冲时间。
- [ ] 我没有同时推进超过 2 个主线项目。
- [ ] 课程出现风险时，我会优先保课程。
