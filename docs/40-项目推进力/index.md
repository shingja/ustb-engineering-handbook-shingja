# 卷四 · 项目推进力

这一卷不告诉你“做什么项目”，因为每年赛道、政策、评审口味都在变。它只给判断框架：

- 这项竞赛值不值得投入。
- 这个题目能不能在时间和能力范围内做完。
- 队友怎么分工，失败了怎么退出。
- 申报书、答辩、复盘分别该准备什么。

## 本卷章节

- [竞赛值不值得参加](竞赛值不值得参加.md)：认可度、能力匹配、时间成本、复用性。
- [选题：从问题出发](选题从问题出发.md)：题目来源、筛选标准、最小可行题目。
- [组队与分工](组队与分工.md)：角色、交付物、退出机制、沟通节奏。
- [读规则与评分表](读规则与评分表.md)：提交物清单、评分表反推、时间线。
- [项目管理与周报](项目管理与周报.md)：里程碑、任务板、周报、风险登记。
- [申报书写作](申报书写作.md)：结构、证据链、常见扣分点。
- [原型与实验](原型与实验.md)：最小闭环、迭代、测试、成本。
- [答辩准备](答辩准备.md)：PPT 结构、讲稿、问答、演示风险。
- [复盘方法](复盘方法.md)：目标 vs 结果、决策回顾、可复用资产。
- [学业平衡](学业平衡.md)：时间预算、优先级、止损。
