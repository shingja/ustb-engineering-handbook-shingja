# FAQ

## 这本手册是什么

**是竞赛题库吗？**
不是。它讲方法、工具、流程和边界，不提供可直接提交的项目方案。

**为什么不给具体方向？**
方向每年都变，照搬别人的方案既容易过时，也可能涉及未公开内容。手册给判断框架，方向自己选。

**软件版本过时了怎么办？**
每篇末尾有“版本与时效”。优先看官方文档；发现过时可在 issue 里标“章节+日期+变化点”。

## 竞赛

**比赛越多越好吗？**
不是。每学期 1-2 个主线，做完整，比报 5 个各做一半更有用。

**校级奖有用吗？**
看学校认定文件。保研/评奖只认名录内赛事和规定级别，以当年文件为准。

**没获奖是不是白做？**
不是。交付物、测试记录、复盘都能复用到下一个项目；失败经验本身也有价值。

**队友不干活怎么办？**
先对交付物和时间线，再谈分工调整；组队时就应该写清退出机制。

## 工具

**一定要用 Git 吗？**
代码/文档建议用。只写 Word 且不协作，可以先用“日期+版本”命名，但迟早会遇到版本/协作问题。

**Typora 收费吗？**
Typora 是付费软件，有试用期。预算有限可以用 VS Code + Markdown 插件。

**Python 用 conda 还是 venv？**
纯 Python 项目用 venv/uv 就够；需要 C/Fortran 依赖/多版本科学计算，用 conda。

**Excel 还是 Python？**
几万行以内、以展示为主，Excel 够用；数据大/需要复现/自动化，用 Python。

## 开源与安全

**私有仓库转公开要注意什么？**
先做隐私/许可/Git 历史检查；删除当前文件不等于删除历史。

**别人搬运我的内容怎么办？**
保留证据，联系平台；如果对方去掉署名/商用，按许可条款处理。

**AI 写的代码能直接用吗？**
不能。要运行、解释、测试、复现；核心内容按竞赛/课程规则声明。

**怎么证明我是原作者？**
可见归属行 + 零宽指纹 + 哈希清单 + 签名提交/tag + 官方地址。

## 手册使用

**可以转载吗？**
正文 CC BY-NC-SA 4.0：署名、非商业、相同方式共享；代码/模板 MIT。

**可以用于社团培训吗？**
非商业分享可以，需署名并附仓库链接；商业培训需书面授权。

**发现错误怎么反馈？**
开 issue，写清文件、章节、问题、建议；安全问题走私密报告。
