# 数学建模工作台

[shingja's Math Modeling Workbench](https://github.com/shingja/shingja-math-modeling-workbench)

面向北京科技大学同学，也适合任何想学数学建模的人。

## 它解决什么

数学建模比赛里，三个人各干各的，最容易在交接时掉信息：建模的假设没传给写代码的，代码的结果没传给写论文的，最后图表、数值和正文对不上。

这个工作台把一道赛题拆成四段，每段都有固定交付物和质检门禁：

| 代号 | 中文 | 负责 |
|---|---|---|
| **Linger** | 徘徊 | 读题、拆子问题、选模型、写假设 |
| **Tide** | 潮起 | 求解、仿真、出图、写复现清单 |
| **Gloom** | 沉郁 | 证据链、论文初稿、排版、图表引用 |
| **Yearn** | 心生惦念 | 终审、W2 门禁、提交包、AI 声明、复盘 |

## 里面有什么

- 12 类 **164 张范式卡**：优化、预测、评价、图论、统计、机器学习、机理、综合、代理模型、鲁棒优化、MCDM、经典。
- **228 个 MATLAB `.m`** + 等价 Python 实现。
- **6 道门禁**：`M1` / `P1` / `C1` / `P2` / `W1` / `W2`。
- 出版级出图：Okabe-Ito 色板、300 DPI、SVG + PNG、布局与设计双检查。
- 论文合规：官方模板、OMML 可编辑公式、三线表、交叉引用、AI 使用声明、提交包清理。
- 可复现：随机种子、输入 SHA-256、依赖版本、唯一复现命令写入 `复现清单.json`。

## 适合谁

| 你的情况 | 怎么用 |

## 怎么开始

仓库地址：

https://github.com/shingja/shingja-math-modeling-workbench

安装、触发词、目录结构和验证命令都在仓库 README。它不生成答案，也不代写论文；它负责流程、门禁和可复现性，模型选择、代码实现和文字论述仍由你和队友完成。使用 AI 时按当届竞赛规则声明。

## 边界

- 生成的论文仅供参考，格式以目标竞赛当届官方规则与模板为准。
- 不伪造数据、不编造结果；异常与不确定必须披露。
- 题目、附件与官方模板的版权属于原权利人。
