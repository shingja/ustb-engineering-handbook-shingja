# 软件清单

## 选择原则

1. 工具服从任务，不要为了用工具而用工具。
2. 优先选能导出通用格式、能长期维护的工具。
3. 学校有正版授权的，优先用正版。
4. 破解版/来路不明的“绿色版”不碰：安全、合规、稳定性都不划算。
5. 同一类工具只留 1-2 个，减少切换成本。

## 自检清单

- [ ] 每类工具只留 1-2 个。
- [ ] 学校有正版授权的优先用正版。
- [ ] 没有用来路不明的破解版。
- [ ] 能导出通用格式。
- [ ] 重要数据有备份。

## 版本与时效

软件清单会过时。安装前看官网当前版本和许可；学校正版授权以信息化办公室/学院通知为准。
