# 北京科技大学竞赛名录（2026-09 版）

> 名录会随年份调整；保研/评奖认定以学校当年文件为准。不要只按“加分”选赛，先看能力匹配、时间成本和成果复用性。

## 怎么用这份名录

1. **先看级别**：国际级/国家级/省部级/校级，对应学校认定和附加分口径不同。
2. **再看时间**：避开考试周和主线项目冲刺期。
3. **看参赛对象**：有些赛项限专业、限年级、限团队人数。
4. **看赛项**：同一个大赛不同赛项，认可度和难度可能不同。
5. **做减法**：每学期 1-2 个主线，做完比报多更重要。
