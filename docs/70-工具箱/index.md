## 使用原则

1. 工具服从任务，不要为了用工具而用工具。
2. 优先选能长期维护、能导出通用格式的工具。
3. 涉及账号、密钥、隐私的工具，先看安全说明。
4. 清单不是越长越好，能执行才有用。
