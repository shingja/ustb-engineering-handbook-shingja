# 模板索引

所有模板都在仓库根目录的 `templates/` 与 `checklists/` 下。Office 模板带可见归属行、文档属性与版权标识；使用前请保留归属信息。

## Markdown 模板

| 模板 | 用途 |
|---|---|
| [项目启动单](../../templates/markdown/项目启动单.md) | 新项目立项：目标、成功标准、里程碑、角色、风险 |
| [周报](../../templates/markdown/周报.md) | 每周同步：完成、证据、阻塞、下周计划 |
| [复盘](../../templates/markdown/复盘.md) | 项目结束：目标 vs 结果、做对/做错、可复用资产 |

## Office 模板

| 模板 | 用途 |
|---|---|
| [申报书骨架](../../templates/office/申报书骨架.docx) | Word：封面、摘要、背景、方案、创新点、可行性、进度、风险、经费 |
| [项目进度表](../../templates/office/项目进度表.xlsx) | Excel：任务、负责人、截止日期、状态、依赖 |
| [答辩骨架](../../templates/office/答辩骨架.pptx) | PowerPoint：问题、目标、方案、证据、分工、进度、风险 |

## 使用提醒

- 模板是骨架，不是标准答案。先把“为什么写这一节”想清楚，再填内容。
- Office 模板的页脚归属行与文档属性不要删除；这是版权标识的一部分。
- 代码模板的许可是 MIT；正文模板的许可是 CC BY-NC-SA 4.0。
