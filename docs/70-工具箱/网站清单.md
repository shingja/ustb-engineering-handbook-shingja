# 网站清单

## 学校与政策

- 学校官网/教务处/学院官网：培养方案、竞赛认定、保研政策。
- 学校信息化办公室：正版软件、VPN、邮箱。
- 学院/团委通知：竞赛报名、材料提交、公示。
- 图书馆：数据库、查收查引、文献传递。

原则：政策以“当年官方文件”为准，不要用二手整理版。

## 学术检索

| 网站 | 用途 |
|---|---|
| Google Scholar | 跨库检索、引文追踪 |
| Web of Science | SCI 检索、引用分析 |
| Scopus | 跨学科检索 |
| CNKI | 中文期刊/学位论文 |
| arXiv | 预印本 |
| PubMed | 生物医学 |
| IEEE Xplore | 电子/计算机 |
| ScienceDirect | Elsevier 期刊 |
| SpringerLink | Springer 期刊 |
| DOI.org | 通过 DOI 找原文 |

## 软件与开发

- 官方文档：Python、Git、GitHub、VS Code、MATLAB、SolidWorks 等。
- GitHub：仓库、Issue、Release、Actions。
- Stack Overflow：具体报错。
- MDN：Web 前端。
- Read the Docs：开源项目文档。
- 菜鸟教程/廖雪峰：入门（注意时效）。

## 数据与统计

- 国家统计局：宏观数据。
- 世界银行/OCED：国际数据。
- 万得/Wind（学校账号）：金融数据。
- Kaggle/UCI：公开数据集。
- 国家地球系统科学数据中心：地理/遥感。
- 中国裁判文书网/专利检索：法律/专利。

## 设计与素材

- Unsplash/Pexels：免费图片（看许可）。
- Iconfont/Iconify：图标。
- ColorBrewer：配色。
- diagrams.net：在线画图。
- Mermaid Live Editor：在线渲染。

## 效率与工具

- TinyPNG：图片压缩。
- PDF24：PDF 合并/压缩。
- DeepL/彩云小译：翻译（核对原文）。
- Overleaf：在线 LaTeX。
- Zotero Connector：网页文献抓取。

## 使用原则

1. 先找官方/一手来源，再看二手整理。
2. 看发布日期/适用版本。
3. 关键结论交叉验证两个独立来源。
4. 不用来路不明的“内部资料/付费保过”。
5. 保存链接、标题、日期，写材料时能回溯。

## 自检清单

- [ ] 政策类信息来自学校/学院官网。
- [ ] 学术检索用过至少两个数据库。
- [ ] 软件问题先看官方文档。
- [ ] 图片/字体/数据确认许可。
- [ ] 关键结论有两个独立来源。
- [ ] 保存了链接和访问日期。

## 版本与时效

网站会改版/失效。本文只列类别和常用入口，具体链接以当前官网为准。
